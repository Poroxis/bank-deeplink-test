# Bank deeplink test

Тестовая страница с вариантами диплинков Сбера и ВТБ.

Публичный адрес: <https://poroxis.github.io/bank-deeplink-test/>

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация

GitHub Actions автоматически собирает и публикует сайт в GitHub Pages после
каждого изменения ветки `main`.
